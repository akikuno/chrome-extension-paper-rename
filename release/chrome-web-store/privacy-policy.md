# プライバシーポリシー

「論文PDFの自動ファイル名変更」は、Chromeでダウンロードする論文PDFのファイル名を、書誌情報に基づいて変更するための拡張機能です。

## 端末内で扱う情報

拡張機能はChromeのダウンロード情報から、ダウンロード元のURL、リダイレクト先、ファイル名、ファイル形式を読み取ります。任意のサイトアクセスを許可した場合は、HTTPSページの公開されている引用タグや構造化データから論文の書誌情報と本文PDFのリンクを読み取ります。論文ページとPDFのURLの対応、および取得した書誌情報はChromeのセッション内に保存し、最長2時間まで照合に利用します。サイトアクセスを取り消すと、このセッション情報を消去します。命名書式は同じChromeプロファイルのローカルストレージに保存します。

## 外部サービスへの送信

書誌情報を取得するため、CrossrefにDOI、Europe PMCにPMCIDまたはDOIを送信します。サービス提供者は、送信された論文識別子と通信時に生じるIPアドレスなどを、それぞれのポリシーに従って取り扱います。拡張機能は、PDF本文、閲覧ページのURL、ログイン情報、命名設定をこれらのサービスへ送信しません。

開発者のサーバーへの情報送信、広告目的の利用、利用状況を計測するための送信は行いません。Chromeウェブストアのユーザーデータに関する限定利用の要件に従います。
